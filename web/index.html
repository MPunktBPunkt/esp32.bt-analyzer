Typische Abläufe

  1. Bridges prüfen → Tab HCI / Proxy: beide Agents ready, Client = Lab-Host, Coex prefer_bt.
  2. Pairing Handy↔BMW → Tab Pairing: Fenster öffnen, am Gerät bestätigen (DisplayYesNo).
  3. Air-Trace → Tab btmon: HCI wählen, Start, Filter z. B. RFCOMM / BD-Adresse.
  4. F20 / CDS / RHMI → Tab BMW Lab: Auth-Mode wählen, CDS setzen, iDrive-Preview bedienen.
  5. HCI aufzeichnen → Tab Capture / BTAC: Target wählen, Start BTAC oder PROXY dual.

On-Chip-Topologie (`.88`/`.89`) und Drain/Inject liegen unter Nodes / Peer bzw. Capture.

HCI-Agents sind die ESP32-D1s als BlueZ-Controller über TCP :9754. Kurve: zum Controller = Host→ESP (Befehle/ACL TX), zum Host = ESP→Host (Events/ACL RX). Nach 5 s ohne Verkehr friert die Kurve ein (letzter Burst bleibt sichtbar).
